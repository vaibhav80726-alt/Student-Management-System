# Student Management System
Student Management System is a web-based application built using PHP and MySQL to simplify the process of managing student records.
It allows users to add, view, update, and delete student information through an easy-to-use interface.

## Features
* Add new student records
* View student details
* Update existing information
* Delete student records
* Store and manage data using MySQL
* Simple and user-friendly interface

## Technologies Used
* PHP
* MySQL
* HTML
* CSS

## About the Project
This project was developed to strengthen my understanding of backend development, database connectivity, and CRUD operations. 
It demonstrates how PHP and MySQL can be used together to build a practical data management application.
